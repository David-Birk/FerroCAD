# Disclaimer

**I am not a Rust developer.**

This project is vibe-coded, and I want to state explicitly that:

- I don't write the code.
- I test the code for security and performance.

I know many people don't like vibe-coded apps, or vibe coding in general. If that's the case, well,
then don't use ferrocad, don't complain, and stay with your Windows system.

## Why ferrocad

I have been using Arch Linux as my daily driver for 2 years now. I always had a Proxmox server with a
tiny10 VM for my CAD work, but it doesn't need to be that complex.

So I searched for alternatives. I tried FreeCAD, Onshape, and so on... The cryinkfly installer (Fusion 360 on Linux) wasn't
really great either, even when I made custom Wine prefixes. My graphics driver always freaked out.

On top of that, Fusion might be the most convenient and easy-to-understand CAD software, but I hate
that it needs an internet connection. I love being able to work offline on the go, so most web
applications aren't an option either.

After a week of struggling with FreeCAD and switching back to Fusion again (which is only usable with
low latency in my home network), and the news about open-source Adobe products, I thought: why not
try to vibe-code a CAD program like FreeCAD, but with the simplicity of Fusion?

## Scope

I only design things for my custom Voron, and this software isn't intended for professional use. But
if the future brings many interested people and progress, it might even become capable of
professional use one day.

This is a hobby project, not pro-level paid software. It isn't connected in any way to Autodesk or
FreeCAD.
